核心理念

          
一次打包好，版本固定、长期复用、直接分发给他人

          

            把「万能工具箱」拆成「专用小家电」：通用 Agent 宿主擅长探索，而当工作流已经跑顺，需要长期稳定自用或发给同事、客户使用时，独立固化的桌面客户端远比共享窗口更省心。
          

        


        

          

            PACK ONCE, REUSE
            
一次打包好，后续长期重复使用

            
生成的不是网页快捷方式，而是自带完整运行时的独立桌面软件。配好一次后，制作器退出、离线断网或长期反复启动，工作台与本地数据都稳定可用。

          

          

            FROZEN VERSIONS
            
dsh 与插件版本双固定，不因升级失效

            
安装包内置锁定版本的 Electron、Node、dsh 宿主与全部业务插件锁（plugins.*.lock.json）。外部 dsh 或社区插件以后升级改版，已打包软件绝不会突然打不开；想升级时再主动重打覆盖即可。

          

          

            READY TO SHARE
            
直接分发给其他人，双击即用

            
直接把 .exe 等安装包发给同事、朋友或客户，对方无需安装 Node、无需安装 dsh、也无需自己找插件配环境，双击安装后即刻直达专属业务首页。

          

        


        

          

            
在单个 dsh 窗口里混装所有插件

            
    
              
  • 写标书、改海报、审合同的会话与工作区混在同一窗口，切换成本高且易串数据。
    • 
              
  • 要发给同事或客户使用时，对方必须自己装 Node / dsh、配置插件源、排错依赖冲突。
    • 
              
  • 上游 dsh 升级或插件版本漂移，容易导致「昨天还能用的流程今天突然报错」。
    • 
            

          


          

            
用 dsh-self 生成专属独立客户端

            
    
              
  • 一次打包、版本锁定：内置固定的 Electron、Node、dsh 与插件依赖锁，长期稳定复用，不惧上游升级破坏。
    • 
              
  • 直接分发、零门槛上手：安装包发给其他人双击即可安装运行，打开直达专属业务首页，无多余弹窗与遥测。
    • 
              
  • 完全隔离、安全演进：独立 productId、internalSlug、userData 与工作区，同机多开零干扰，后续可按需主动重打覆盖升级。
    • 
            

          

        

      

    


    

      

        

          
dsh-self-studio 工作台

          
6 步闭环，从一句话到可安装软件

          

            仅依赖官方 dsh@0.2.2-rc.5 公开原语（ctx.connection / ctx.slots / ctx.locale / ctx.layout），在 dsh web 与官方桌面端一致可用。
          

        


        

          

            01
            
写需求

            
输入一句话描述，支持调用 dsh 默认模型扩写完整需求草稿（无模型时自动离线补全）；支持参考图、SSRF 护盾读取参考网址或导入既有 product.json。

          

          

            02
            
选方案

            
即时产出极简版 / 标准版 / 专业全功能版三套方案，自带浅色/深色 1:1 桌面窗口预览；仅在答案改变工作流时做最少追问。

          

          

            03
            
选插件

            
执行四步静态准入与六维冲突过滤，自动识别本机已装 DSH 插件，支持按能力切换候选；遇到 peer 冲突（如 13 项宿主冲突）明确拦截并给出标准 MCP 替代方案。

          

          

            04
            
改外观

            
编辑中英文名称、语义化版本、图标（4 套 SVG 预设或自定义图片）、8 项亮暗语义种子色（派生 110+ --dsw-* 变量并保证 WCAG 4.5:1 对比度）及首页模块顺序。

          

          

            05
            
试用微调

            
通过独立子进程与隔离 Session 分区运行 1:1 预览；视觉与排序改动秒级热刷新，支持右侧自然语言对话微调与任意历史修订一键回退。

          

          

            06
            
生成安装包

            
由独立信任根 tools/builder 校验快照并出包，支持 Windows x64 本地直打 NSIS .exe，以及跨平台便携迁移包、GitHub Actions 工作流与 Docker/远程脚本，附带 SHA-256 与版本历史管理。

          

        

      

    


    

      

        

          
工程纵深

          
默认隔离、可升级、可自愈的安全架构

          

            每一层边界都经单元与契约测试固化，不把提示词或外部网页当成可信控制面。
          

        


        

          

            IDENTITY & UPGRADE
            
不可变身份与可变品牌分离

            
创建时冻结 productId、internalSlug、nsisGuid 与 appUserModelId。后续可随时改名换图标升级，NSIS customInit 清理旧快捷方式、跨 GUID 同名自动追加 (<shortId>) 并阻断旧版降级覆盖。

          

          

            CaMeL + SSRF
            
双通道污点分离与双层防 SSRF

            
视觉与网页抽取严格拆分 controlSafe（闭集枚举）与 taintedDisplay（绝不回流规划 LLM）；独立 fetch-worker 拦截回环、私网、云元数据 169.254.169.254、CGNAT、NAT64 与非 80/443 端口。

          

          

            PREPACKAGED + FUSES
            
三步预打包与双槽自愈回滚

            
只读 base-shell 预固化安全 Electron Fuses（RunAsNode: false、OnlyLoadAppFromAsar: true），纯 JS resedit 钤印后由 --prepackaged 封包；运行期按 seedHash 切换 p-<hash> 双槽，2 次冷启失败自动回滚。

          

          

            OOXML & SHARP
            
文档沙箱与超长图无上限导出

            
投标适配器实施 ZIP 炸弹四重配额、剥离 w:altChunk/UNC 路径，并在 opaque-origin <iframe sandbox="allow-scripts"> + 严格 CSP 下预览；设计画布自动归一化 EXIF 旋转，逐标注分块合成突破 Cairo 32,767 px 硬上限。

          

        

      

    


    

      

        

          
获取 dsh-self-studio

          
安装官方 DSH 插件（v0.1.0 发布准备版）

          

            声明 engines.dsh: ">=0.2.2-rc.1 <0.3.0" 与 engines.node: ">=24.9"，已在官方 dsh@0.2.2-rc.1 桌面端与 0.2.2-rc.5 实机通过 10 项插件发布自动化门禁。
          

        


        

          

            

              
方式一：本地源码打包并安装（立即可用）

              当前可用
            

            
在 dsh-self 仓库中运行 10 项门禁校验并打出标准 .tgz，直接装入官方 dsh profile：

            

              

                shell
                
              

              
node scripts/prepare-plugin-release.mjs --pack
dsh plugin --profile web add .dev/plugin-release/dsh-self-studio-0.1.0.tgz
dsh web

            

          


          

            

              
方式二：npm / 自定义插件索引（公开发布后生效）

              待维护者推送 npm
            

            
公开推送至 npm 后，可直接按版本安装，或在 DSH「设置 → 插件 → 发现」添加下方官方自定义索引源：

            

              

                shell / index url
                
              

              
# npm 精确版本安装
dsh plugin --profile web add dsh-self-studio@0.1.0

# 官方 DSH 自定义插件索引 URL（format: 1）
https://dsh-self.octoooo.com/dsh/index.json

            

          

        


        

          诚实披露：本机直接生成的 Windows NSIS 安装包属于未签名测试/内测包（unsigned-local-test），经网络传输会触发 Windows SmartScreen 提示；Host 插件运行于宿主进程内并拥有当前系统用户文件与网络权限。完整发布检查清单见 插件发布准备指南。
